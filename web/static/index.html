What is this?

An AI coding assistant that can read/write files, run commands, and run tests — all under safety guardrails that block dangerous actions and ask for your approval.

Quick Start (3 steps)

  1. Click Settings (top right) → enter your OpenAI API key
  2. Type a task below (e.g. "write hello.py that prints hello world")
  3. Watch the agent work — approve any actions it asks permission for

Example Tasks

Write a fibonacci function → fib.py
Create and run hello.py
List files in directory
Write a calculator with tests

How it works

1 You type a task in natural language
2 AI decides what files to read/write, what commands to run
3 Safety guardrails block dangerous commands (rm -rf, sudo, etc.)
4 Risky actions (git push, pip install) require your approval
5 Agent runs tests and self-corrects from failures
